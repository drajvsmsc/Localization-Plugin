Noun Filtering

About Noun Filtering:

The extension can exclude certain types of nouns from localization checks to reduce false positives.

Brand names, product names, person names, places
Examples: "Google", "iPhone", "John Smith", "New York"

Translation Verification

ℹ️ About Translation Verification:

Translation verification is enabled by default using LibreTranslate at http://localhost:5001 in full verification mode.

Example: If a page shows "Casa" for "Home", but the correct translation should be "Início", it will be flagged as incorrectly translated.

💡 Make sure LibreTranslate is running locally on port 5001, or change the URL below.

Enabled by default - uncheck to disable translation verification

Default: http://localhost:5001 (Local instance)
Change this if your LibreTranslate server is on a different port or server
